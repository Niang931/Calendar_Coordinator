## Shared Calendar Coordinator

This is an overview of the project

## Individual Users

- can register, log in
- have private calendar system
- do not share schedule across users
- can rank other users for preference

## Personal Calendar

- create, edit and delete events/ tasks
- view tasks and update the UI
- remind the users about upcoming deadlines/ events
- each event has a rank of importance, urgency

## Meeting Proposal

- user can propose a meeting request
- required: participants
- optional: meeting time
- participant involved has to first approve the proposal to initiate the time negotiation

## Availability

- calculated upon the user's calendar
- in accordance with the events and user's constraints
- shared across users when negotiating an event timeline

## Meeting Negotiation

- upon proposal, user has to input the importance and urgency of the meeting
- based on the availability period, the timeline will be arranged
- if not meeting timeslot was produced, based on the comparison between the ranking of the new proposal and existing events, suggestion about reoving the existing event will be displayed.
- require user's last approval to the event

## TimeZone Synchronization

- time difference will be considered for users from different regions

## Further implementation

- accountability partner
- users can keep track of one another's personal goal progress
